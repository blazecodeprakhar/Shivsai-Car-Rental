# Shivsai-Car-Rental

Modern, responsive web platform for **Shivsai Car Rental** — offering premium self-drive car rentals, local hourly packages, one-way outstation cabs, and airport transfers.

## 🚀 Features
- **18 Verified Vehicles**: Real photo galleries, daily/per-km rates, seating capacities, and fuel variants.
- **Swipe & Drag Gallery**: Touch swipe and drag controls to browse vehicle photos.
- **Anti-Download Protection**: Disabled image context menu and drag-to-save for professional asset protection.
- **WhatsApp Booking Dispatch**: Seamless booking flow pre-filling trip details, vehicle name, and rates sent to `+91 93714 12111`.
- **Fast Performance**: Compressed WebP imagery reducing asset payload by 90% for instant loading on mobile and desktop.
- **Tailwind CSS & Motion**: Micro-interactions, sticky navigation, and infinite running marquee.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
